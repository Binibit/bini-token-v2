# Security Policy

Do not disclose a suspected vulnerability in a public issue or pull request.
Contact the Binibit security owner through the private channel published by the
organization before deployment. The organization must add a monitored security
email or GitHub private vulnerability reporting link before mainnet
authorization.

Include:

- affected commit and contract;
- impact and preconditions;
- reproducible transaction or test;
- whether funds, governance or availability are at risk;
- any suggested mitigation.

This repository is an engineering candidate and has not yet completed the
required independent external audit. The known architectural limitations are
documented in `docs/security/THREAT_MODEL.md`.
