# BINI V2 External Audit Package

This directory is the RC2 auditor entry point. Review the repository at the
exact successful CI SHA and download `bini-v2-release-evidence-<SHA>` from that
run. The artifact contains raw logs, build-info, bytecode and local receipts.

The package is pre-audit and blocked on real Sepolia receipts. It must not be
represented as an external audit report or Mainnet authorization.
