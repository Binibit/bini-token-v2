# RC2 Audit Package

The `audit-package/` directory defines scope, canon, threat model, roles, test
inventory and known limitations. The exact-SHA CI artifact supplies raw build,
analysis, test and local receipt evidence. ABI, selectors, storage and bytecode
hashes remain version-controlled under `artifacts/release/`.

Sepolia addresses and confirmed receipts are intentionally absent because no
real deployment occurred. Phase 2 execution and all Phase 3 activity are out of
scope. External audit has not started.
